# bobo.ai 第二轮修订记录

触发：用户指出手柄按钮朝向观众，与试玩动作不符。首轮审查漏检了动作逻辑。

## 本轮检查与修订目标

| 对象 | 首稿问题 | 修订目标 |
|---|---|---|
| 所有手柄 | 按钮面竖直朝向观众、双手抱两侧 | 按钮面朝上并向角色倾斜；手掌握柄、拇指落在控制面；观众主要看到背壳和上沿 |
| 策划 | 看向观众，缺少读图动作 | 视线落在图纸、手部自然支撑 |
| 画师 | 工具与视线不足以表达工作 | 画笔指向实际绘制对象，动作与对象接触 |
| 工程师 | 操作姿态不明确 | 屏幕朝向角色，双手操作键盘或支撑设备，目光看屏幕 |
| 测试员 | 手柄反向，工坊内无明确试玩屏幕 | 加入桌面显示器；屏幕朝角色，人物视线对准显示器 |
| 工作台流程 | 代码阶段仍进行、测试员却在试玩 | 统一到验证中：代码已完成、验证进行、完成待办，记录同步 |
| 活跃任务控制 | 画面没有明确停止入口 | 顶栏补充停止制作 |
| 小字与按钮 | 浅橙底白字、部分灰字偏浅 | 提高文字明度差，橙色按钮改深色字；正式实现仍需计算对比度 |
