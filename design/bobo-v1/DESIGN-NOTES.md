# bobo.ai · 设计记录（第二轮修订）

状态：视觉提案；不是已获确认的最终设计系统。

用户已选定：温暖潮玩、圆润小怪兽、奶油白与橙色、创作伙伴感。方案图片使用内置 imagegen 生成；首页和工作台均以角色设定板为身份参考。

## 角色

主角是一个橙色软胶小怪兽，主要识别点是高低不一的圆角、奶油色脸腹、可可色眼睛、小牙、短尾巴与圆脚。同一物种通过工具和服装区分岗位。已有图里部分小尺寸表情的小牙会简化，正式资产阶段需要逐张统一。

## 首页

让用户马上看见创意输入区和开始制作入口。波波的桌面小景作为陪伴和品牌记忆，项目列表与设置容易找到。概念图中的欢迎插画占比较大，落地到小屏桌面时应缩小或折叠，优先保留输入框。

## 工作台

保持项目栏、制作流程、事件记录、输入区、游戏预览、素材与文件入口。工坊插画集中表现四位伙伴的工作；真正的制作状态仍由文字、进度和事件表示，不能仅依赖角色动作。

## 后续制作要求

- 图标单独出稿；不从这张设定板直接裁切当最终图标。
- 动画角色需透明底、统一尺寸与脚底锚点，适配原有 manifest 的 16 类动作。
- 生成的 UI 文字仅作排版参考，最终实现用真实文本、图标组件和可访问控件。
- 主操作按钮的文字对比度需要加深橙色或使用深色文字；不要直接从效果图取色后宣称可访问性达标。
- 首页与工作台的游戏项目、状态和缩略图均是示例内容，不是实际用户数据。
- 后续改名应区分展示名称、应用标识、用户数据目录与内部通信字段，避免全局字符串替换带来兼容问题。
- 开发在 dev 上进行，main 继续保留上游同步用途。

## 本轮边界

交付三张新视觉图、原版素材与对照提案册。尚未交付完整动画库、深色皮肤、全部设置页面或可运行换肤版本。远端仓库未改名，未推送提交，未发布。
