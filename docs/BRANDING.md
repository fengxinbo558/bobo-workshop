# BoBo 品牌规范

产品展示名为「波波工坊」，英文署名为「BoBo」，IP 角色为「波波」。

- 应用、Web/Godot 初始工程、Agent 策划/实现/审核提示词、生成的说明文件、素材工具与导出内容使用同一品牌。
- `build/icon.png` 是已批准的橙色波波图标；创建游戏时复制到 `resources/bobo-runtime-icon.png`，供平台图标使用。游戏保留自己的标题与自定义美术，不强制加入水印。
- 新 Agent 工具使用 `bobo_*`，新游戏生产技能使用 `bobo-game-builder`。旧会话的工具调用保留兼容入口。
- 已有游戏启动升级时更新宿主说明、旧默认图标和品牌文字，并重新导出 Godot 预览。玩法代码与游戏名称不整体覆盖。
- 交付检查扫描公开源码和文本导出中的旧名称。位图内的文字与旧 IP 由视觉审核检查；静态扫描不等于 OCR 保证。
- `.noobi` 元数据目录、IPC、历史设置字段和已保存的原始事件保留兼容，它们不作为产品名、署名或水印。用户数据目录也保留，以便继续读取账号、项目和凭证。
- 上游来源归属保留在仓库文档中，主分支继续接收原仓库更新。

验证：模板品牌与图标一致性、旧项目迁移、导出文本检测、旧工具兼容测试，以及真实 Godot 导入/检查/Web 导出冒烟。
